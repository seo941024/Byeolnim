PWA(홈 화면에 추가) 아이콘 4종. manifest.json / index.html이 이 파일명 그대로 찾으므로
이름을 바꾸지 마세요. 교체할 때는 아래 규격만 지키면 됩니다.

  icon-192.png           192 x 192   안드로이드 설치 아이콘 (필수)
  icon-512.png           512 x 512   스플래시 화면 (필수)
  icon-maskable-512.png  512 x 512   안드로이드가 원형/둥근네모로 잘라 쓰는 용도
  apple-touch-icon.png   180 x 180   아이폰 홈 화면

★ 파일마다 모서리 처리가 다른 이유 (중요)
  - icon-192 / icon-512 : 둥근 모서리를 직접 넣는다. (현재 반지름 14%)
  - apple-touch-icon    : 각지게, 불투명하게 둔다. iOS가 자기 방식(스퀘어클)으로
                          깎기 때문에 미리 둥글리면 그 바깥이 검게 남는다.
                          투명 배경도 금지 — iOS가 검정으로 합성한다.
  - icon-maskable       : 각지게, 꽉 채워 불투명하게 둔다. 안드로이드가 직접
                          잘라내므로 미리 둥글리면 잘린 자리에 틈이 생긴다.
  결과적으로 폰에서는 넷 다 둥글게 보이지만, 파일 자체는 서로 다르다.

현재 아이콘은 메이플 캐릭터 일러스트를 정사각형에 꽉 차게(cover) 잘라 만들었다.
여백을 남기면(contain) 좌우에 배경색 띠가 생겨서 그렇게 하지 않았다.
배경색은 manifest.json의 background_color(#0d0922)와 맞춰 스플래시와 이어지게 했다.

PNG는 palette 압축으로 용량을 약 80% 줄였다(512 기준 616KB -> 123KB).
화질 차이는 육안으로 확인되지 않았다.
