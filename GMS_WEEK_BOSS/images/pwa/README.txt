여기에 아이콘 4개를 넣으면 PWA(홈 화면에 추가)가 완성됩니다.
파일명은 그대로 지켜야 manifest.json / index.html이 찾습니다.

  icon-192.png           192 x 192   안드로이드 설치 아이콘 (필수)
  icon-512.png           512 x 512   스플래시·스토어용 큰 아이콘 (필수)
  icon-maskable-512.png  512 x 512   안드로이드가 원형·둥근네모로 잘라 쓰는 용도
                                     → 로고를 가운데 80% 안에 두세요.
                                       가장자리 10%는 잘려나갑니다.
                                       배경은 투명 말고 꽉 채워주세요.
  apple-touch-icon.png   180 x 180   아이폰 홈 화면 아이콘
                                     → 투명 배경 금지(검게 나옴), 모서리 둥글리지 마세요.
                                       iOS가 알아서 둥글게 깎습니다.

배경색은 manifest.json의 background_color(#0d0922)와 맞추면 자연스럽습니다.
